# T400 Oracle Cases

This companion is normative for Task 7 of `2026-08-28-t400-animation-sampler.md` and removes any need to invent expected values during implementation.

All values below come from the committed S004 GeckoLib 4.4.9 oracle at `spikes/geckolib-animation-semantics/artifacts/results.json` / `expected/expectations.json`.

## Exact cases

- `EASE-001` — 1.0 s rotation `[0,0,0] -> [1,1,1]`, linear. At 25/50/75% the real Gecko x/y samples are `-0.004363323129985824`, `-0.008726646259971648`, `-0.013089969389957472` radians and z is the positive counterpart. A T400 test can sample at 4 FPS SINGLE, whose times include 0, 1/3, 2/3, 1, or use a direct channel/evaluator test for the exact 25/50/75 oracle fractions. Do not pretend a non-grid time is a grid assertion.
- `EASE-002` — step easing. Oracle semantic expectations: sample25 = `0.0`, sample50 = `0.0`, sample75 = `-0.00872664626` on rotation X; raw observed sample75 is `-0.008726646259971648` radians. Use direct `RotationChannelSampler`/evaluator assertions at 0.25, 0.5, 0.75 s if the uniform T400 grid does not contain all three times for the selected timeline.
- `EASE-003` — `easeinsine`. Oracle rotation-X raw observations at 25/50/75% are `-0.001328552785835346`, `-0.0051119510250589445`, `-0.010774206632339446` radians. The normalized easing progress at 50% is `0.2928932188` (full evaluator value `0.2928932188134524`).
- `POSITION-001` — parser/oracle expected first `[1,2,3]`, last `[2,3,4]`; use it to prove position evaluation is independent from rotation/scale.
- `SCALE-001` — expected first `[1,1,1]`, last `[2,2,2]`; `SCALE-002` proves explicit zero scale is data, not a missing-channel identity.
- `KEYFRAME-003` — oracle observes independent stack sizes `3/2/2`; use the committed source fixture to prove T400 evaluates each component/channel against its own timestamp sequence rather than assuming a common source grid.
- `ROTATION-001` — authored X `190°` survives parser semantics.
- `ROTATION-002` — authored X `720°` survives parser semantics and is the required winding regression input.
- `ROTATION-003` — authored X sequence `[350°,10°]` is explicitly marked `shortestPath=false`; T400 must preserve scalar authored interpolation semantics and must not replace it with quaternion shortest-path interpolation.

## Required assertion policy

Task 7 must include at least:

1. one parser→sampler integration using `EASE-001`, `EASE-002`, or `EASE-003`;
2. one independent-channel integration using `KEYFRAME-003` or `POSITION-001` + `SCALE-001`;
3. one rotation continuity integration using `ROTATION-002` or `ROTATION-003`;
4. expected numbers copied from this file/S004, never generated by the implementation under test;
5. exact-time comparisons only. If an S004 oracle fraction is not on the selected uniform `TimelineGrid`, call the lower-level channel sampler at that exact time or choose a rate/duration whose grid contains it; do not compare nearest-frame values.
